# Portfolio — Josue Villegas

## How to publish this on GitHub Pages

1. Create a new repository on GitHub named exactly `your-username.github.io` (use your real GitHub username).
2. Add these files (`index.html`, `style.css`, `script.js`, and the `assets` folder) to the root of that repository.
3. In the repo, go to **Settings > Pages**. Under **Source**, select the `main` branch and the `/root` folder. Save.
4. Wait 1–5 minutes. GitHub will show your live URL on that same Settings > Pages screen: `https://your-username.github.io`

## Before publishing, replace the placeholders

- `assets/profile.jpg` — your photo, shown in the hero section.
- `assets/josue-villegas-cv.pdf` — your CV, once you export it as a PDF.

The introduction video is already embedded from YouTube, no local video file needed.

## Local preview

Just open `index.html` directly in a browser, no build step needed.
