04 — Projects

Academic projects

OSAA Motors

Django · Flutter · MySQL

A full management system for auto repair shops, with a web platform and a mobile app working together. I helped design how the system's information was organized, built the sections where staff can manage records like inventory and clients, and worked on how the different parts of the system connected with each other.

SIGA

Django REST Framework · Flutter · MySQL

A web system that simulates real customs administration operations: package registration, required documentation, and pedimento generation, following the process carried out at an actual customs office. Built as a team project. I contributed to setting up the database, resolving conflicts when multiple team members worked on the same code, and documenting how the system was structured so the whole team could build on it.
